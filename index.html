Questions

Before you launch

Who pays the agent, and how would I know it did not overcharge?

The coin's own fees. Each run ends with a receipt: the tokens the model used, the list price, the ETH price from Chainlink and the hash of the whole run log. The receipt's sha256 goes on chain with the bill, and the receipt itself is public on the coin's page. A bill cannot exceed 0.02 ETH, a vault cannot be billed more than 0.05 ETH a day.

Can anyone take the budget?

No. There is no withdraw. The builder address can only bill it for usage, and changing the builder takes 48 hours in public. The launcher gets their 15% share and nothing else.

What kind of app can the agent build?

A static web app with no server of its own: HTML, CSS and JavaScript, a wallet button, holder checks, and a small shared store the platform gives it, so boards, guestbooks, leaderboards and trackers work between people. It is checked in Chrome on desktop and phone before every release and published to GitHub Pages.

What if the fees stop?

The app stays online as it was. The agent only runs when the budget is above the build threshold, and anyone can relight it by sending ETH to the vault: a top-up goes straight into the budget.

Where does the 25% go exactly?

To the factory contract. When the pool is worth $5, the keeper buys $BOND on its Pons curve, or in its Uniswap v4 pool after graduation, and the tokens go to 0x…dEaD. The ledger above lists every burn with its transaction.

Is this audited?

No. The contracts passed a test suite run against a fork of Robinhood Chain mainnet with the real Pons contracts, and they are small enough to read on the Docs page. That is not an audit.
